## 📖 Repository Overview

This repository brings together hands-on front-end learning and practice projects into a unified learning hub:

- **HTML5 Semantic Markup**: Structural tags, tables, and diverse form controls with validation.
- **CSS3 Styling & Modern Layouts**: Box model, border styling, geometric shapes, Flexbox centering, and responsive design techniques.
- **JavaScript Core Fundamentals**: Variables (`let`), arithmetic operations, user prompts, type conversions, conditional logic, and interactive scripts.
- **Mini Projects**: Complete landing pages and portfolio templates.

## 📚 Modules & Curriculum

### 1. HTML & CSS Module (`HTML & CSS/`)
- **Semantic HTML**: Document structuring, headings, paragraphs, and media embedding.
- **Forms & Inputs**: Text fields, radio buttons, checkboxes, dropdowns, and fieldsets.
- **Tables**: Multi-column student database tables with custom borders and styling.
- **CSS Concepts**: Box model (`margin`, `padding`, `border`), custom geometric shapes, and Flexbox alignment.
- **Mini-Projects**: 
  - College Landing Page
  - Personal Portfolio Template

### 2. JavaScript Module (`JAVA SCRIPT/`)
- **Language Fundamentals**: Variable declarations with `let`, arithmetic operators (`+`, `/`), and assignment.
- **Input & Output**: Interactive user input using `prompt()`, output rendering via `document.write()`.
- **Type Casting**: Explicit numerical conversions with `Number()`.
- **Control Flow**: Conditional branching with `if...else` statements and credential authentication.

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/lakshyakurvey19-code/Web-Development.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd Web-Development
   ```

3. **Open exercises in your browser:**
   - Open any `.html` file directly in a modern web browser (Chrome, Firefox, Edge).
   - Alternatively, open the folder in **VS Code** and use the **Live Server** extension for hot-reloading.
