## 📖 About the Repository

Welcome to my **HTML & CSS** practice repository. This repository archives my practical exercises and hands-on front-end learning as a 3rd-semester IT student:

- **Semantic Document Markup**: Headings, paragraphs, media embedding, and links
- **Forms & Input Controls**: Labels, text inputs, radio/checkboxes, fieldsets, and validation
- **Tabular Data**: Structured tables with headers, borders, and styled cells
- **CSS Box Model & Styling**: Border styling, padding, margins, and geometric shapes
- **Flexbox Layouts**: Content centering and flexible container alignment
- **Practical Mini-Projects**: A college landing page and a personal portfolio page

## ⚡ How to Run Locally

Preview any of these pages directly in your browser:

1. **Clone this repository**:
   ```bash
   git clone https://github.com/lakshyakurvey19-code/HTML-and-CSS.git
   cd HTML-and-CSS
   ```

2. **Open any page**:
   - Double-click any `.html` file (e.g., `Projects/college-portal/main.html`), or
   - Use the **Live Server** extension in VS Code (`Right-click -> Open with Live Server`).
