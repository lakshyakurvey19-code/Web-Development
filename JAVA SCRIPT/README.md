# JavaScript Practice Programs

A repository containing beginner-friendly JavaScript practice examples and foundational exercises implemented using internal scripts within HTML files.

---

## 📂 Project Structure

```text
JAVA SCRIPT/
├── Internal js/
│   ├── 001_hello.html
│   ├── 002_Calculate_Percentage.html
│   ├── 003_addOf2.html
│   ├── 004_login_system.html
│   ├── 005_name_age.html
│   ├── 006_name.html
│   └── 007_take_add2.html
└── README.md
```

---

## 📋 Program Index

| File | Topic / Description | Concepts Used |
| :--- | :--- | :--- |
| **001_hello.html** | Hello World | Basic JavaScript syntax, `document.write()` |
| **002_Calculate_Percentage.html** | Subject Marks & Percentage Calculator | `prompt()`, `Number()` casting, arithmetic operations, multi-variable handling |
| **003_addOf2.html** | Static Addition of Two Numbers | Variable declaration (`let`), addition operator |
| **004_login_system.html** | Basic Login Authentication System | Nested `if...else` statements, string comparison, input validation |
| **005_name_age.html** | User Information Input & Display | Taking string & numeric inputs, formatting output |
| **006_name.html** | Student Details Profile | Variables, string concatenation, HTML line breaks (`<br>`) |
| **007_take_add2.html** | Dynamic Addition of Two Numbers | User input via prompt, type conversion with `Number()`, summation |

---

## 💡 Key Topics Covered

- **Variables & Declarations:** `let`
- **User Interaction:** `prompt()` for user input
- **Output:** `document.write()` with HTML tags
- **Data Types & Type Conversion:** Strings, Numbers, `Number()` function
- **Operators:** Arithmetic (`+`, `/`), Assignment (`=`), Comparison (`==`)
- **Control Flow:** Conditional statements (`if`, `else`, nested `if`)

## 🚀 How to Run

1. Clone or download the repository:
   ```bash
   git clone https://github.com/lakshyakurvey19-code/Java-Script.git
   ```
2. Navigate to the project directory:
   ```bash
   cd "Java-Script/Internal js"
   ```
3. Open any `.html` file in your preferred web browser (e.g., Chrome, Edge, Firefox), or use the **Live Server** extension in VS Code.
